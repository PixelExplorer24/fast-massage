# Firebase Rules — Realtime Database

The app no longer uses Cloud Firestore.

Publish `database.rules.json` here:

Firebase Console → Realtime Database → Rules → Paste → Publish.

The rules are designed for the RTDB paths used by this app:

- `/users`
- `/friends`
- `/friendRequests`
- `/groups`
- `/messages`
- `/calls`
- `/presence`
- `/typing`
- `/notifications`
